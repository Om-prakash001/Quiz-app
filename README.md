# Quiz App

A clean and responsive quiz application built with React and Node.js.

## Features
- Category-based quizzes
- Timed quiz sessions
- Multiple-choice questions
- Result summary with correct and wrong answers
- Leaderboard for score tracking

## Tech Stack
- React
- React Router
- Zustand
- Tailwind CSS
- Node.js
- Express
- MongoDB
